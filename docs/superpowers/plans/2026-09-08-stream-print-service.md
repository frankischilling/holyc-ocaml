# StreamPrint task service implementation plan

> Use superpowers:executing-plans for serial implementation and verification.
> Independent reviews are read-only; root owns edits and executable use.

**Goal:** Execute checked StreamPrint calls into the active task generation
buffer, retaining separate ordinary output and shared formatting work limits.

**Architecture:** Reuse the existing checked extern-call classification and
Integer_output formatter. Opaque task stream tokens select a LIFO stack of
buffers. Each buffer has the same task work budget; generated bytes have their
own cumulative capacity. Finishing returns only that buffer's bytes; aborting
discards its text while retaining reached work and generation charges.

**Tech stack:** Existing OCaml, Dune, Alcotest and checked integer IR.

**Spec:** `docs/superpowers/specs/2026-09-08-stateful-exe-design.md`.

## Constraints

- Retain branch `feat/635-stateful-exe`, reference
  `c26482bb6ad3f80106d28504ec5db3c6a360732c`, packages and dependencies.
- This service is required by the complete parser/runtime connection. It does
  not replace the fourteen real #exe gates, native publication and pending
  execution, query/identifier receipts, or whole-command source authority.
- Ordinary Print/PutChars formatting, atomic/prefix output behavior and measured
  execution/preparation/allocation counts remain unchanged.
- Source-defined replacements use their own bodies. Name alone does not grant
  service execution: exact checked extern/header metadata and an active task
  generation buffer are both required.
- Foreign, reused or out-of-order stream tokens cannot inspect/pop another
  buffer. Generated text is returned only by a successful finish.

## Following integration work

The source-execution facade must sit above an extracted compilation-unit core
and Integer_task to avoid their current dependency cycle. It must receive the
caller's limits before parsing and retain output/work on later compile errors.
Create the separate AOT task environment before reading outer AOT declarations;
JIT outer commands and blocks share one task. Keep ordinary no-#exe compilation
on its existing single-unit path and measured resource counts. Stateful bundles
need an honest artifact projection and a VM-owned cumulative result snapshot.
Parser command receipts, selected-reference consumption and partial global/
header/initializer admission precede that connection; do not fabricate AST
wrappers or recompile a prefix to make the original gates pass.
