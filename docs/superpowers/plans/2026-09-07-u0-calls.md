# U0 function execution implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement and review these tasks. Root serializes builds and executable use.

**Goal:** Execute ordinary U0 source calls through the checked program pipeline, preserving side effects, caller continuation and successful completion without a word.

**Architecture:** Extend the existing private VM call protocol with checked void completion. Keep the public word and termination types, direct-call lowering, return lowering, memory operand classes and resource limits. A U0 call-end retains its result identity and produces a private marker that only a checked discard may consume.

**Tech stack:** OCaml, Dune, Alcotest, existing checked HolyC IR.

**Spec:** Issue #619 and Section 56 of the external requirements file. Native reference: `c26482bb6ad3f80106d28504ec5db3c6a360732c`.

## Constraints

- Keep `Type.equal`, function/frame/symbol identity and exact call cleanup checks.
- A U0 return occupies no value or frame slot. Never fabricate an I64 zero.
- Distinguish pending completion, completed void and completed word. An ignored word call cannot satisfy the enclosing function's required word return.
- Preserve graph-only execution, all previous storage domains and checked resource accounting.
- Keep U0 value-return and missing word-return restrictions labeled as hosted boundaries; native `PrsStmt.HC:1110-1118` warns about these forms.
- Use the existing Git identity helper. Require independent review and all five checks on the final source before protected merge.
